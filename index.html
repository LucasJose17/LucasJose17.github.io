O que eu construí

San's Pizza

Sistema de pedidos para uma pizzaria de Mamanguape – PB: o cliente pede pelo celular, a equipe acompanha no balcão e na cozinha, e o dono administra tudo num painel.

Cliente

Entra só com nome e celular, sem senha. Vê o cardápio, monta o pedido e o endereço fica salvo para a próxima vez.

Balcão e cozinha

A equipe entra com a conta Google e acompanha os pedidos no painel do balcão e da cozinha.

Administração

Um painel separado, só para o dono, acompanhar a operação da pizzaria.

Decisões técnicas

  • Banco no Supabase com segurança por linha (RLS): cada usuário só enxerga os próprios dados.
  • Validação de dados com Zod e TypeScript no modo estrito.
  • Testes unitários com Vitest e de ponta a ponta com Playwright, incluindo checagem de acessibilidade.

Feito com

Next.js · React · TypeScript · Tailwind CSS · Supabase · Auth.js · Zod · Vitest · Playwright
